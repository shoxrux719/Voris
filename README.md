# Voris Turobov

Портфолио мобилографа и видеографа Voris Turobov на React, TypeScript и Vite.

## Локальный запуск

```bash
npm install
npm run dev
```

## Заявки в Telegram

Форма внизу страницы отправляет имя, фамилию и телефон через серверный маршрут `/api/lead`. Скопируйте `.env.example` в `.env` и заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Бот должен иметь право публиковать сообщения в указанном канале. Файл `.env` исключён из Git; токен не попадает в браузерную сборку.

Для запуска сайта с рабочей формой на сервере с Node.js:

```bash
npm install
npm run build
npm start
```

Порт по умолчанию — `4173`; можно задать переменную `PORT`. На статическом хостинге для `/api/lead` потребуется отдельная серверная функция.

## Развёртывание на Vercel

Подключите репозиторий к Vercel. Файл `vercel.json` задаёт Vite, команду `npm run build` и папку результата `dist`; версия Node.js — 22.x.

Маршрут `api/lead.mjs` запускает обработчик заявок как Vercel Function. В настройках проекта добавьте переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` для нужного окружения и выполните новое развёртывание. Файл `.env` в Git не публикуется.

Готовые MP4 и обложки в `public/assets/videos` находятся в обычном Git и доступны сайту без Git LFS. Для публикации исходников MOV из `public/assets/VD` включите Git LFS в Settings → Git проекта Vercel, затем выполните новое развёртывание.

## Подготовка видеоработ

Исходники находятся в `public/assets/VD`. Скрипт создаёт обложки и MP4-версии 1080p/720p с H.264, AAC и fast start в `public/assets/videos`:

```bash
python -m pip install imageio-ffmpeg
python scripts/prepare-videos.py
```

Список и подписи работ задаются в `src/data/films.ts`. Скрипт также создаёт `src/data/video-assets.ts` с адресами MP4, содержащими хеш файла: новые версии не конфликтуют с длительным кешированием браузера и CDN.

Плеер начинает с облегчённой версии 720p; 1080p можно выбрать вручную. Обе версии используют H.264, 30 кадров/с, AAC и fast start. Видео загружается только после выбора работы; сервер поддерживает частичные запросы для перемотки. Скрипт удаляет прежние MP4-версии только после успешной подготовки всех новых файлов; исходники MOV сохраняются.

Для просмотра используются HLS-потоки с фрагментами по 2 секунды: Safari воспроизводит их напрямую, остальные поддерживаемые браузеры — через загружаемый по требованию `hls.js`. MP4 остаётся резервным вариантом. `python scripts/prepare-videos.py --package-only` обновляет HLS без повторного сжатия MP4.
